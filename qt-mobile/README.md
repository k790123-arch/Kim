# TV기독교채널 QT 업로더

매일 오전 6시에 시작하는 QT 제작 예약에서 검수된 영상이 도착하면 한국시간 오전 7시 10분 공개를 YouTube에 예약하는 Android 앱입니다. 갤럭시 탭 S9을 먼저 쓰고 갤럭시 S25+는 예비 기기로 사용합니다. 이미 접수된 예약은 YouTube가 실행합니다.

## 처음 연결할 때

1. GitHub Actions의 **QT mobile APK** 성공 실행에서 **tv-qt-android**를 내려받아 압축을 풉니다. 같은 빌드의 **TV-QT-Uploader.apk**를 두 기기에 설치합니다. ZIP 안의 **certificate.txt**와 앱 첫 화면에서 서명 SHA-1을 확인할 수 있습니다.
2. [Google Cloud API 라이브러리](https://console.cloud.google.com/apis/library)에서 같은 프로젝트에 **YouTube Data API v3**, **Google Drive API**, **Google Sheets API**를 사용 설정합니다. Google Auth Platform에서 앱 이름·연락처와 대상 사용자를 설정합니다. 외부 테스트 앱으로 운영한다면 채널 소유 계정을 테스트 사용자에 추가합니다.
3. [Google Auth Platform 클라이언트](https://console.cloud.google.com/auth/clients)에서 **클라이언트 만들기 → Android**를 선택합니다. 패키지에 `kr.tvqt.uploader`, SHA-1에 위 빌드의 서명 값을 입력합니다. 두 기기에 같은 APK를 설치하면 등록 항목 하나를 함께 사용합니다. 자동 빌드를 다시 실행하면 서명 키가 바뀔 수 있습니다. 재설치·업데이트 전에 새 인증서와 일치하는지 확인합니다.
4. 탭에서 앱을 열어 **갤럭시 탭 S9 (우선) → Google 계정 연결 · 자동 업로드 켜기**를 누릅니다. 채널과 비공개 업로드 기록표를 소유한 Google 계정으로 승인합니다. 앱은 채널과 기록표를 모두 확인한 뒤 켜집니다. S25+도 같은 순서로 **갤럭시 S25+ (예비)**를 선택합니다.
5. 앱의 **지금 상태 확인**으로 연결 상태를 점검합니다. 첫 영상은 [YouTube Studio](https://studio.youtube.com/) 콘텐츠에서 대상 채널, 영상 제목, 예약 날짜와 시간을 함께 확인할 수 있습니다. 앱의 **이 기기 자동 업로드 중지**로 해당 기기를 중지하고 **Google 계정의 연결 관리**에서 승인 자체를 철회할 수 있습니다.

### 기기에서 요청하는 권한

YouTube 업로드와 읽기 권한은 영상 전송, 채널 및 예약 시각 대조에 씁니다. Drive 읽기와 Sheets 수정 권한은 Google 동의 화면에서 계정 전체 범위로 표시됩니다. 앱은 해당 계정이 소유한 비공개 대기 폴더와 그 안의 업로드 기록표를 사용하며, 영상은 전송 전 앱 전용 캐시에 잠시 내려받습니다. 계정 비밀번호·인증 JSON을 입력할 필요가 없습니다. 같은 Google 계정에 채널이 여러 개인 경우 권한 승인 결과가 지정 채널과 일치해야 합니다.

### 매일 공개되는 편성

월~금 QT는 90초, 토·일 QT는 120초입니다. 월·목에는 성경 이야기, 화요일에는 재미있는 성경 이야기, 토요일에는 건전하고 재미있는 세상 이야기의 150초 본편과 20초 요약을 추가합니다. 기존 제작 예약이 완성 MP4와 게시 문구를 전달합니다. Android 절전·네트워크·YouTube 처리 시간에 따라 대기열 확인과 전송 시각은 달라질 수 있습니다. 두 기기가 모두 오프라인이면 새 예약 접수를 할 수 없습니다.

### 대기열과 중복 방지

앱은 비공개 Drive 폴더 **TV기독교 QT 업로드 대기**와 원본 Google 시트 **TV기독교 QT 업로드 기록**을 찾습니다. `업로드` 탭의 A:I는 편 식별자, 제목, 설명, Drive 파일 ID, 바이트, SHA-256, 검수 상태, 공개 예정 시각, 업로드 상태입니다. `기기` 탭 B2/B3는 각 기기의 마지막 응답 시각입니다. 2026-11-23의 2행에서 시작해 하루 3행(QT·본편·요약)을 배정합니다. 제작 과정은 검증을 마친 MP4에만 A:H를 채웁니다. 날짜·종류·SHA-256·파일 크기·공개 시각이 일치해야 전송합니다. I열은 처음에 `READY`이며 앱이 한 셀의 이전 상태와 일치할 때만 인계하거나 갱신합니다.

영상 데이터를 보내기 전에 YouTube 전송 세션을 비공개 기록에 저장합니다. 연결이 끊기면 그 세션의 수신 위치부터 이어가며 Google이 완료 여부를 확인해 주지 못한 건은 Studio 확인 대상으로 남깁니다. 공개 시각을 지난 작업에는 새 데이터를 전송하지 않습니다. 기록표의 접근 권한은 본인으로 유지하세요. 상태 열에 임시 세션 주소가 포함될 수 있습니다.
